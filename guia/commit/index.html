Commit: tirar a foto do jardim

Edite, escolha o que entra e tire a foto. O commit salva no seu computador.

No jardim

Você planta, arranca e faz um caminho de pedras. Depois põe na bandeja só o que quer mostrar e tira a foto, que vai para o armário de fotos.

Na prática

São três lugares: a pasta de trabalho (onde você edita), a área de preparo, ou staging area (a bandeja com o que vai entrar na foto) e o histórico local (o armário com as fotos, os commits).

O git add põe mudanças na bandeja. O git commit tira a foto do que está na bandeja e guarda com uma frase. O git status mostra, a qualquer momento, o que mudou e o que já está na bandeja.

Comandos

git status  # o que mudou?
git add .  # tudo para a bandeja
git commit -m "Adiciona o caminho"  # tira a foto B

Atenção: Um commit não envia nada para ninguém. Ele salva só no seu computador.
